### 版本发布 (Releases)

#### 开发中版本 (Development)

**Hydra 1.4** 是 Hydra 当前的开发主线版本：
- Hydra 1.4 正式版即将发布。在稳定版发布前，您可以从 PyPI 安装开发预览版。
- [官方文档 (Documentation)](https://hydra.cc/docs/intro/)
- 安装命令：`pip install --pre --upgrade hydra-core`
- 支持的 Python 版本：Python 3.10 至 3.14。

#### 稳定版本 (Stable)

**Hydra 1.3** 是 Hydra 当前的稳定发行版：
- [官方稳定版文档](https://hydra.cc/docs/1.3/intro/)
- 安装命令：`pip install hydra-core --upgrade`

查阅 [NEWS.md](NEWS.md) 文件了解 Hydra 近期版本的改动与特性摘要。
